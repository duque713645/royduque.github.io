# Roy Duque IT Portfolio

Files:
- index.html — main portfolio website
- assets/Roy_Duque_Resume.pdf — downloadable resume

To add review screenshots:
1. Put JPG/PNG files in the assets folder.
2. Replace the four review-placeholder blocks in index.html with image elements.
3. Remove names, email addresses, ticket numbers, customer information, and confidential company data unless you have permission to publish them.

The site is static HTML/CSS and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or similar static hosting.
